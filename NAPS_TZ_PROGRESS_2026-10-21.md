## Сделано в этом продолжении

### Следующая итерация: редактирование пересечений

1. Автоматическим узлам и фрагментам проводов SCM 8 добавлены сведения о происхождении. Они сохраняются в файле; SCM 7 эти поля не получает. При редактировании исходные проводники восстанавливаются из фрагментов, после изменения маршрута общий нормализатор заново определяет геометрические пересечения и строит электрические узлы. Режим `explicit` остаётся без нормализации.
2. Общий механизм теперь вызывается при построении провода и после drag-переноса провода, его сегмента, элемента или группы. Удалённое геометрическое пересечение перестаёт объединять сети. В распознавании соединений учтены X, T, L, коллинеарное наложение и совпадающие концы.
3. Исправлена группировка истории при drag: начатый ранее короткий таймер больше не закрывает непрерывную операцию. Перенос пересечения и последующая нормализация отменяются одним Ctrl+Z и повторяются одним Ctrl+Y.
4. Расширены unit-тесты геометрии, электрического графа, SCM 7/8, сохранения происхождения проводов и группового переноса. Браузерный тест проверяет редактирование существующей трассы, исчезновение старого электрического узла, сохранение, undo/redo.

Проверки этой итерации: `npm run lint`, `npm run test`, `npm run build` и `npm run test:browser` пройдены. Сборки Windows и проверка запуска будут отмечены отдельно после фактического выполнения.

1. Для новой пустой схемы включён режим соединяемых пересечений. Пересечение нового провода с другой электрической сетью материализуется как `JUNCTION`: оба маршрута разбиваются, граф `buildCircuitGraph` получает общую сеть. Обрабатываются прямое пересечение и коллинеарное наложение. После первого соединения сети повторно не разбиваются. Undo/redo восстанавливает провод и узел одной операцией.
2. Для SCM добавлена версия 8 с `Topology.Crossings: connect`. Файлы версий 1–7 открываются с прежней семантикой `explicit` и не получают новых соединений при загрузке. При экспорте старой схемы сохраняется SCM 7. Координаты в миллиметрах и существующие маршруты не пересчитываются из-за версии топологии.
3. Добавлены A0 (841×1189), A1 (594×841), A2 (420×594) мм в тот же модуль `printLayout`, меню печати и сериализацию SCM. Существующая бесконечная рабочая область и масштаб экрана не менялись. Размеры PDF проверены по `MediaBox`.
4. Быстрая панель и библиотека размещения показывают пять базовых двухполюсников (источник напряжения, источник тока, R, C, L). Полный каталог моделей сохранён для чтения старых SCM и расчётов; загрузка, редактирование и повторное сохранение скрытого NPN проверены в браузере. Разделение этих пяти семейств на зависимые и нелинейные варианты ещё не завершено.
5. Открытие меню примеров закрывает режим многократной установки, чтобы баннер установки не перехватывал выбор схемы.
6. Четыре отдельные кнопки экспорта заменены одной кнопкой «Экспорт» с пунктами SVG, PDF, PNG и «Печать». Существующие настройки, предварительный просмотр и физический масштаб остались прежними. Браузерный экспорт PNG и A3 PDF пройден через новое меню.

## Следующие инженерные риски

Единый нормализатор добавлен для построения и drag-правок, но остаются крайние случаи удаления отдельного фрагмента автоматического узла, ручного переподключения концов, поворота и клавиатурного переноса элемента. Их нельзя считать проверенными. Следующая крупная задача — единые варианты двухполюсников с реальными нелинейными моделями, без декоративных переключателей.
