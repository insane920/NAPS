# NAPS

**NAPS — Numerical, Analytical, PWL, Simulation** — локальное CAD-приложение для создания электрических схем, расчёта переходных процессов и частотного анализа. Результаты отображаются на графиках и сопровождаются подробностями расчёта. Для работы не нужны API-ключи, облачный сервис или сервер.

## Возможности

- Редактор схем с палитрой компонентов, готовыми примерами, масштабированием, поворотом элементов, настройкой свойств и горячих клавиш, отменой и повтором действий.
- Проводка доступна прямо в редакторе: контакт подсвечивается при наведении. Соединение можно начать нажатием или протягиванием от контакта — отдельный режим включать не требуется.
- Ручной маршрут провода с горизонтальными, вертикальными и 45-градусными участками. Подключение к существующему проводу создаёт видимый узел; простое пересечение линий электрически их не соединяет.
- Несколько проводов могут подключаться к одному контакту. Редактор предотвращает повторное соединение той же пары контактов; провода можно перемещать и удалять.
- Импорт и экспорт схем в читаемом формате `.scm`, включая параметры компонентов и настройки расчёта.
- Расчёт переходных процессов по топологии проводов: R/L/C-элементы, независимые источники, диоды, управляемые ключи, тиристоры, операционные усилители, двухобмоточный трансформатор, логические элементы, компаратор и RS/D/JK-триггеры.
- Частотный анализ (АЧХ/ФЧХ) с настройкой диапазона частот, графиками амплитуды и фазы и деталями комплексного расчёта.
- Графики и таблицы сигналов, экспорт CSV и автономный HTML-отчёт с формулами, промежуточными и итоговыми значениями.
- Расчёты выполняются в Web Workers и не блокируют редактор.

## Как соединить элементы

Наведите курсор на вывод элемента — контакт выделится. Нажмите на него и затем на контакт другого элемента либо протяните провод мышью. Щелчки по свободному полю добавляют точки маршрута. Для ответвления подключитесь к существующему проводу: редактор создаст узел. Выбранный провод удаляется клавишей Delete.

## Локальный запуск

Понадобится Node.js 22.12 или новее. Выпуск установщика и portable-версии настроен для Windows.

```powershell
npm ci
npm run dev
```

Запуск Electron-приложения из исходников:

```powershell
npm run electron:start
```

## Проверка и сборка

```powershell
npm run lint
npm run test
npm run test:browser
npm run build
npm run dist:win
```

`npm run lint` проверяет TypeScript, `npm run test` запускает расчётные и проектные тесты, а `npm run test:browser` проверяет действия в редакторе. Для локального запуска браузерных тестов нужен Google Chrome; путь к другому совместимому браузеру можно задать через `NAPS_CHROME_PATH`. Команда `npm run test:all` запускает оба набора тестов.

`npm run build` создаёт веб-сборку в `dist/`. На Windows `npm run dist:win` выпускает установщик и portable-приложение в `release/`. GitHub Actions на Ubuntu проверяет TypeScript, тесты, браузерные сценарии и веб-сборку; Windows-пакеты этот процесс не создаёт.

## Ограничения моделей

NAPS предназначен для обучения, исследования и разработки, но не является сертифицированным симулятором.

- Конденсаторы и катушки рассчитываются неявным методом Эйлера. Ограничения решателей — до 20 000 точек времени и 160 электрических неизвестных.
- Диод, ключ и тиристор используют настраиваемые кусочно-линейные модели. Операционный усилитель моделируется с конечным усилением и ограничением выходного напряжения. Паспортные особенности реальных приборов учитываются не полностью.
- Компонент `TR3` — двухобмоточный трансформатор с четырьмя выводами. Потери в обмотках и насыщение сердечника не моделируются.
- AC-анализ поддерживает линейные элементы и линеаризацию поддерживаемых нелинейных приборов около рабочей точки постоянного тока. Частотные характеристики цифровых элементов, компаратора и триггеров не рассчитываются.
- Отдельный сравнительный сценарий преобразователя на RK4 не участвует в расчёте схем из редактора.

Перед применением результатов к реальному оборудованию или производственному проектированию проверяйте их независимым средством и по документации компонентов.
