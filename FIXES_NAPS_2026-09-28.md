# NAPS 1.0.1 — исправления после аудита

Исходные шаги воспроизведения и приоритеты перечислены в `AUDIT_NAPS_2026-09-28.md`. Этот документ фиксирует результат работы. Исполняемые Windows-файлы собраны, но не запускались по согласованному объёму проверки.

| Ошибка | Исправление | Проверка |
| --- | --- | --- |
| NAPS-01, P1: новая схема наследовала сигналы примера; расчёт простой цепи выдавал ошибку | Новая и очищенная схема получают пустой список сигналов. При первом расчёте автоматически выбирается напряжение первого подходящего элемента. Очистка сбрасывает элементы, провода, настройки и имя одним отменяемым действием. | Браузер: пустой список сигналов, расчёт цепи V–R–GND, загрузка примера → очистка → undo/redo. |
| NAPS-02, P0: `1кк` отображалось как 1кк, а рассчитывалось как 1 Ом | Инженерный номинал теперь разбирается целиком; неизвестная приставка отклоняется в свойствах элемента и при импорте. Для R/L/C требуется положительное число. | Математические проверки и браузер: отказ для `1кк`, сохранение корректного `2к`. |
| NAPS-03, P1: после удаления R2 добавлялся второй R3 | Имя выбирается выше наибольшего занятого номера; ручное переименование с конфликтом отклоняется. | Браузер: R1, R2, R3 → удаление R2 → новый R4; ручной конфликт отклонён. |
| NAPS-04, P0: SCM с `X: wrong` помещал элемент с `NaN` | Координаты, номиналы, параметры расчёта и другие числовые поля валидируются до замены проекта. Проверяются повторные имена и согласованность видимого номинала с числом. | Браузер: ошибочный SCM оставляет текущий проект; тесты: шесть примеров проходят импорт и повторный экспорт. |
| NAPS-05, P2: Tab уходил из модального окна на фон | Добавлен общий цикл фокуса и возврат на кнопку открытия для библиотеки, свойств, параметров расчёта, редактора SCM, графиков и помощи. | Браузер: Tab/Shift+Tab внутри библиотеки, возврат фокуса при закрытии. |
| UI-02, P3: свойства и параметры расчёта выглядели неоднородно | Заголовки и кнопки закрытия приведены к светлой теме библиотеки. | Визуальная проверка интерфейса в браузере. |

Также сохранение SCM в Electron переведено на запись во временный файл с последующей заменой целевого файла; это снижает риск обрезания существующего проекта при ошибке записи. Браузерные сценарии добавлены в CI.

После правок прошли `npm run lint`, `npm run test`, `npm run test:browser` и `npm run build`; команда `npm run dist:win` завершилась успешно и повторно выполнила типизацию, тесты и сборку. Браузерный набор включает проводку, диагонали 45°, пересечения с узлом и без узла, параллельные ветви, редактирование трассы, перемещение и поворот подключённых элементов, SCM, расчёты, графики и экспорт. Успешный тест относится к этим сценариям, а не ко всем возможным схемам.

В `release` оставлены только актуальные файлы:

- `NAPS-Setup-1.0.1-x64.exe` — 111 466 517 байт;
- `NAPS-Portable-1.0.1-x64.exe` — 111 330 005 байт.

**Оставшиеся ограничения:** Windows EXE не запускались и установка, IPC, сохранение в реальной настольной среде не проверены. CSP для окна Electron требует проверки совместимости с `file://` и worker при отдельном настольном прогоне. Длительные и нагрузочные сценарии, профильное сравнение сложных математических моделей с эталонным симулятором и поддержка узких мобильных экранов остаются вне проведённой проверки.
