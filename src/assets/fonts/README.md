# OpenGOST Type A

`OpenGOSTtypeA-Regular.ttf` взят из релиза v0.7 проекта [open-gost-arm](https://github.com/ingenium-am/open-gost-arm/releases/tag/v0.7). Авторская информация и условия распространения — в `OFL.txt` рядом со шрифтом (SIL Open Font License 1.1).

Шрифт используется для подписей на схеме и в основной надписи. В самостоятельный SVG он встраивается как data URI; PDF-экспорт NAPS в текущей реализации растровый, поэтому его текст не остаётся выбираемым. Наличие шрифта не заменяет нормоконтроль размеров текста по ГОСТ 2.304-81.
