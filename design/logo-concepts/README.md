# NAPS — концепции логотипа

Три независимых растровых эскиза созданы встроенным инструментом генерации изображений. У всех прозрачный фон; исходное написание — `NAPS`. Файлы не подключены к приложению и не заменяют текущую иконку.

| Файл | Краткий промпт и идея |
| --- | --- |
| `naps-strict.png` | Строгий технологичный логотип: сетевой геометрический знак из четырёх узлов, мотив буквы N, тёмно-синее слово NAPS, один бирюзовый акцент, плоская форма без декоративных эффектов. |
| `naps-futuristic.png` | Сдержанный футуристичный логотип: переплетённые угловые траектории серебристого и бирюзового цвета, цифровая архитектура, графитово-синий NAPS, чёткая горизонтальная композиция. |
| `naps-minimal.png` | Максимально простая версия: компактный N-образный монограммный знак из широких геометрических штрихов с одним бирюзовым квадратом, контрастное слово NAPS, прозрачный фон и плоские цвета. |

Во всех промптах исключались шестерёнки, лампочки, мультяшность, 3D, градиенты, лишний текст и фоновые панели. Перед использованием в приложении выбранный эскиз следует точно перерисовать в векторном формате и проверить на малых размерах 16–32 px, светлом и тёмном фоне.
