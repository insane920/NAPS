# NAPS — фирменный комплект v1

Знак: геометрическая буква N с отделённым бирюзовым квадратом — узлом или активным элементом системы. Палитра: тёмно-синий `#122641`, бирюзовый `#18C9BD`, светлый `#EDF4FA`. Без градиентов, теней и текстур.

Комплект построен непосредственно в SVG. Надпись нарисована контурами, без внешних шрифтов. SVG масштабируются без потери чёткости. PNG экспортированы из тех же векторных файлов, ICO содержит несколько размеров той же иконки.

## Файлы

- `naps-icon.svg` — квадратная иконка со скруглёнными углами; подходит для обоих фонов.
- `naps-icon-16.png` … `naps-icon-1024.png` — иконка в размерах 16, 24, 32, 48, 64, 128, 256, 512 и 1024 px; прозрачные углы.
- `naps-icon.ico` — Windows-иконка: 16, 24, 32, 48, 64, 128, 256 px.
- `naps-wordmark-light.svg` / `.png` — тёмная надпись для светлого фона.
- `naps-wordmark-dark.svg` / `.png` — светлая надпись для тёмного фона.
- `naps-logo-light.svg` / `.png` — иконка и надпись вместе на светлом фоне.
- `naps-logo-dark.svg` / `.png` — иконка и надпись вместе на тёмном фоне.
- `naps-compact-light.svg` / `.png` и `naps-compact-dark.svg` / `.png` — компактная композиция для панели приложения, базовый размер 168×40 px.
- `naps-brand-preview.png` и `preview.html` — лист сравнения светлого и тёмного вариантов, отдельной иконки, надписи и компактной версии.

Суффикс light/dark обозначает фон, на котором использовать файл. Сам фон в файлах логотипов прозрачный. PNG надписи: 1404×344; общего логотипа: 1632×384; компактной версии: 504×120.

## Использование

Для Linux можно использовать PNG 256/512 px или SVG; для Windows — ICO. На маленьких кнопках и в заголовке окна используйте отдельную иконку. Для панели интерфейса — компактную версию; для splash screen и сайта — общий логотип. Не растягивайте знак по одной оси и оставляйте вокруг свободное пространство минимум в четверть высоты иконки.

Экспорты проверены визуально на светлом и тёмном фоне; иконка проверена на листе в 16/24/32 px. Интеграция в NAPS, замена текущей иконки и пересборка приложения в этот комплект не входят и не выполнялись.
