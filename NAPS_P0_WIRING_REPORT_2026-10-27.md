Ключ сравнения участков теперь не зависит от порядка конечных контактов и направления точек маршрута. Регрессионный тест проверяет ровно четыре ветви вместо пяти, единый электрический узел, ортогональную трассу, сохранение/повторное открытие SCM 8 без восстановления дубликата и 50 повторных переносов узла без потери связности.

После изменения прошли `npm run lint`, полный `npm run test` и `npm run build`. `npm run test:browser` не дошёл до сценариев: Vite сообщил о готовности на `127.0.0.1:3130`, но подключение к локальному порту отклонено с `EACCES`. Поэтому W09 остаётся частичным; браузерное подтверждение этого исправления и полный контроль циклов объединённой сети ещё требуются. EXE, Linux и push не выполнялись.

## Продолжение W09: циклические сети, 28.10.2026

Воспроизведён дефект: два прямоугольных контура с общей ветвью имели 2 независимых цикла в модели, но на экране видимая длина проводников составляла 960 вместо 1280 единиц. Маршрутизатор заставлял каждую замыкающую ветвь следовать уже нарисованному дереву, скрывая две стороны контуров. `routeCircuitWires` теперь отличает замыкающий провод по связности уже проложенных конечных контактов и для него разрешает кратчайшую допустимую трассу. Совпадающие участки одной сети по-прежнему выводятся однократно через `uniqueWireInk`; электрические провода из модели не удаляются.

Автоматические проверки охватывают: один прямоугольный цикл; два цикла с общей ветвью и перестановкой порядка проводов; три T-ветви с общим участком, в том числе обратного направления; единую T/X-сеть с четырьмя циклами; удаление общей ветви (2 цикла → 1, сеть остаётся связной); перенос подключённого резистора; 50 переносов общего узла с возвращением исходной геометрии; сохранение/загрузку SCM 8. Для этих сценариев проверены число вершин проводников, связных компонент, независимых циклов, электрический узел, ортогональность и отсутствие повторно нарисованных участков. Это проверки модели и SVG-геометрии, не фактического взаимодействия мышью.

`npm run lint`, полный `npm run test` и `npm run build` прошли. Браузерные тесты здесь по-прежнему заблокированы: отдельный минимальный Node HTTP-сервер успешно открыл случайный порт `127.0.0.1`, но `fetch` к нему вернул `EACCES`. Проверка прежнего запуска Vite показала тот же отказ соединения. Это указывает на ограничение сетевого доступа текущей среды; в обычной Windows-среде команда: `cd 'D:\FASTMEAN 2.0'; npm run test:browser`. Без результата этой команды сценарии Undo/Redo циклической сети в интерфейсе не подтверждены, поэтому W09 остаётся частичным.

Git: `D:\FASTMEAN 2.0\.git\index.lock` отсутствует; индекс существует, ACL папки разрешает Modify для группы CodexSandboxUsers. Тем не менее `git add` снова получил `Permission denied` при создании `.git/index.lock`. Вероятная причина — ограничение записи в `.git` со стороны текущей среды. Коммит не создан, изменения сохранены в рабочем дереве. Push, merge, rebase, EXE и Linux не выполнялись.

## Браузерная проверка W09, 28.10.2026

Полный `npm run test:browser` запущен в обычной Windows-среде и прошёл, включая новый `browser-w09-cycles.cjs`. Новый сценарий в реальном интерфейсе создал замыкающую ветвь прямоугольного контура, удалил её, перенёс подключённый резистор, выполнил Undo/Redo каждой операции и открыл сохранённый SCM 8. После каждого изменения через сохранённый файл проверены число проводов, связных компонент, независимых циклов и электрических узлов; через SVG проверены точные линии и суммарная видимая длина. Переход 0 → 1 → 0 циклов совпал с добавлением и удалением ветви. После Undo/Redo и повторного открытия геометрия восстановилась. В полном наборе также прошли проверки плотной сети, T/X-пересечений, SCM 7/8, ручных изгибов и многократных перемещений.

Первый полный браузерный прогон остановился на `browser-view-preferences.cjs`: проверка закрытия диалога выполнялась сразу после асинхронной загрузки файла. Отдельный прогон сценария прошёл. Тест теперь дожидается скрытия диалога и сохраняет прежнее утверждение; повторный полный набор прошёл. `npm run lint`, `npm run test`, `npm run build` тоже прошли. W09 переведён в «проверено» для заявленных пользовательских сценариев. Ограничение импорта произвольно повреждённых SCM 8 относится к W01. Производственная сборка выдаёт предупреждение о чанке 544 КБ; EXE не собирался.

Доступ к Git восстановлен при запуске команды записи в обычной Windows-среде. Локальный коммит W09: `ca1d102` (`fix(wiring): preserve cyclic routes and verify W09 interactions`). Push, merge и rebase не выполнялись.
